# 🧠 Sistema de Clasificación de Fallas en Bomba Electrosumergible mediante CNN

Este proyecto implementa un modelo de red neuronal convolucional (CNN) para la
clasificación de condiciones operativas en bombas electrosumergibles a partir de imágenes.

El sistema permite:

- Cargar archivos CSV y generar gráficos polares
- Revisar calidad de datos
- Seleccionar una imagen y obtener la predicción del modelo entrenado (TensorFlow Lite)

---

# ⚙️ Requisitos del sistema

- **Sistema operativo:** Windows 10/11
- **Python:** 3.10.11 ⚠️ (No usar Python 3.12)
- **RAM recomendada:** 8 GB
- **CPU:** compatible con TensorFlow (no se requiere GPU)
